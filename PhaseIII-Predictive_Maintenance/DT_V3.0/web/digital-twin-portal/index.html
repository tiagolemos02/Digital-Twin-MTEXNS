    XACML Help (FIWARE + Authzforce)

    Keyrock must run with advanced PDP mode (`IDM_PDP_LEVEL=advanced`) to accept `permission.xml` rules.

    Typical FIWARE/Authzforce attributes used in rules:

    • `urn:thales:xacml:2.0:resource:sub-resource-id` for resource path matching.
    • `urn:oasis:names:tc:xacml:1.0:action:action-id` for HTTP method matching.
    • `urn:oasis:names:tc:xacml:2.0:subject:role` for role checks.

    Minimal rule template:

    <Rule RuleId="custom-rule-id" Effect="Permit">
  <Description>Allow a role on selected method/path</Description>
  <Target>
    <AnyOf>
      <AllOf>
        <Match MatchId="urn:oasis:names:tc:xacml:1.0:function:string-regexp-match">
          <AttributeValue DataType="http://www.w3.org/2001/XMLSchema#string">^/v2/entities/?(\\?.*)?$</AttributeValue>
          <AttributeDesignator Category="urn:oasis:names:tc:xacml:3.0:attribute-category:resource"
            AttributeId="urn:thales:xacml:2.0:resource:sub-resource-id"
            DataType="http://www.w3.org/2001/XMLSchema#string" MustBePresent="true" />
        </Match>
      </AllOf>
    </AnyOf>
    <AnyOf>
      <AllOf>
        <Match MatchId="urn:oasis:names:tc:xacml:1.0:function:string-equal">
          <AttributeValue DataType="http://www.w3.org/2001/XMLSchema#string">GET</AttributeValue>
          <AttributeDesignator Category="urn:oasis:names:tc:xacml:3.0:attribute-category:action"
            AttributeId="urn:oasis:names:tc:xacml:1.0:action:action-id"
            DataType="http://www.w3.org/2001/XMLSchema#string" MustBePresent="true" />
        </Match>
      </AllOf>
    </AnyOf>
  </Target>
  <Condition>
    <Apply FunctionId="urn:oasis:names:tc:xacml:3.0:function:any-of">
      <Function FunctionId="urn:oasis:names:tc:xacml:1.0:function:string-equal" />
      <AttributeValue DataType="http://www.w3.org/2001/XMLSchema#string">ROLE_ID_HERE</AttributeValue>
      <AttributeDesignator AttributeId="urn:oasis:names:tc:xacml:2.0:subject:role"
        Category="urn:oasis:names:tc:xacml:1.0:subject-category:access-subject"
        DataType="http://www.w3.org/2001/XMLSchema#string" MustBePresent="false" />
    </Apply>
  </Condition>
</Rule>

    References: FIWARE Keyrock PDP configuration, Authzforce integration guide.

    Asset ID help

    The Asset ID is the stable identifier printed on the machine plate in the 3D factory.

    Asset ID
    Short operational identifier, such as HP-2000.
    Machine Name
    Optional human-readable name, such as Hydraulic Press 01.
    Device ID
    Technical identifier used to provision and connect the device.

    Rules

    • Required and unique among the machines visible in the portal.
    • Between 2 and 20 characters.
    • Letters, numbers, hyphens, and underscores only.
    • No spaces; uniqueness is checked without case sensitivity.
    ValidHP-2000CNC_04LINE3-PRESS
    InvalidHP 2000APRESS#04
